## Getting Started

### Prerequisites
- Ubuntu/Debian based Linux environment
- Basic build tools (gcc, make)

### Installation
```bash
git clone https://github.com/MiriYaakobi/vr-portfolio.git
cd vr-portfolio
bash setup.sh
```

### Building the Binaries
```bash
make all
make clean
```
